MAMMALOGY PRACTICAL TRAINER — INTEGRATED VERSION

STARTING
1. Extract the entire folder.
2. Double-click START_MAMMALOGY_TRAINER.bat.
3. The trainer opens in your browser through a tiny local web server.
4. Do not open index.html directly.

FEATURES
- Full Practical, Scientific Name, Family, Skull/Teeth, and Skin/Whole quiz modes.
- Randomized course images and user-added images.
- Typed answers; capitalization/italics do not matter.
- Local progress and missed/unseen weighting.
- Species Study area connected to each species.
- User-created study cards (front/back/category).
- Browse-card and flashcard study modes.
- User-written species notes.
- Copy/paste images directly with Ctrl+V.
- Upload image files if desired.
- Tag images as Skull/Teeth, Skin/Whole, or Mixed.
- Full backup export/import for custom images, study cards, species notes, tags, progress, and settings.

SOURCE NOTES
- Course/source terminology is preserved in the species data. The first two taxa use "Crietidae" in the source, while "Cricetidae" appears elsewhere; both are accepted for those two entries.
- The source did not explicitly provide a family for Mountain beaver (*Aplodontia rufa*); the trainer uses Aplodontiidae so the family field is usable. Verify this against your course materials if needed.
- The app includes the additional end-of-document taxa/images: thylacine, duck-billed platypus, Tasmanian devil, American opossum, coarse-haired wombat, and red kangaroo.

DATA STORAGE
Your added images, study cards, species notes, tags, and progress are stored locally in your browser for this trainer.
Use Export Full Backup regularly. Import the backup after moving to another computer or browser.

UPDATES
Because this is a local app, a new version of the program itself requires downloading/extracting the updated package. Your personal study data can be carried forward using Export Full Backup / Import Backup.
A future hosted version could provide a normal shareable URL where app updates happen centrally without classmates redownloading the program.

IMAGE FIX: Course specimen images are embedded directly in the app so they load even when the folder is opened from a local file or hosted without separate image-path configuration. The images/ folder is retained as the original source-image backup.
