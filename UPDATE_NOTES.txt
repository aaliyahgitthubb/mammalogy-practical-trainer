Mammal Vault v2.1.0
- Added Edit Species for correcting common name, scientific name, family, notes, and clues.
- Rebuilt Blur/Cover mask dragging using pointer events captured at the document level.
- Blur and Cover boxes now use the same drag controller; mouse, touch, and pen input are supported.
- Added pointer-event/user-selection safeguards so the image cannot steal the drag.
- Existing data.js and embedded_images.js are intentionally not included; keep your existing copies.
