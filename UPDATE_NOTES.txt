The Mammal Vault v2.0.5

Multi-box quiz image masking update.
- Each specimen image can have multiple independent blur or cover boxes.
- Boxes can be added, selected, moved, resized, changed between blur/cover, and removed.
- Existing single-box quiz masks remain compatible.
- Each image keeps its own mask layout.
- Add Species image workflow supports multiple mask boxes before the species is saved.
- Quiz renders every saved mask box for that image.
