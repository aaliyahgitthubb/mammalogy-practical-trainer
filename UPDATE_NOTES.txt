1.8.4 — Integrated Image Editor

- Added an integrated image editor under Manage Species & Images.
- Edit image tools include crop, square crop, 90° rotation, horizontal/vertical flip, brightness, contrast, saturation, and output resize.
- Editing creates an edited copy and preserves the original image.
- Course-image edits are stored as browser-local overrides; custom-image edits are stored with the custom image.
- Added Reset image edit for edited course/custom images.
- Existing quiz text-area masks remain separate from image editing.
- Added the same image editor during first-time species creation, before the species is saved.
- First-time image editing preserves the species name, scientific name, family, notes, and clues while editing images.
- First-time images can still receive their per-image quiz text-area mask before saving.
- Backups now include edited custom images and course-image edit overrides.
- 1.8.5 crop fix: the crop selection box is now anchored to the displayed image itself, so the saved crop exactly matches the selected area.
- Updated service-worker cache so GitHub Pages loads the corrected version.

Previous 1.8.3 functionality is preserved, including the Species Library landing page, family grouping, per-image quiz masks, Google Photos import, and image management.
