The Mammal Vault v2.0.6 — Multi-Box Image Masking Coordinate Fix

Replace the update files in the existing GitHub Pages repository.
KEEP data.js and embedded_images.js unchanged.

This update fixes the multi-box quiz-mask editor so mask coordinates are tied to the actual displayed image rather than the surrounding editor/quiz panel.

Features:
- Add multiple independent Blur or Cover boxes to each image.
- Drag boxes to move them.
- Drag the lower-right handle to resize them.
- Select a box and change its mode or blur strength.
- Remove one box or clear all boxes.
- Saved masks are applied to that exact image during quizzes.
- Existing single-mask data remains compatible.
